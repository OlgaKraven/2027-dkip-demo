# Проверка решения

Проверено 28 сентября 2026 года на Windows, .NET SDK 10.0.401, XAMPP/MariaDB 10.4.32 и PostgreSQL 18.

## Программы и данные

- Сборки Windows Forms, WPF, Shared, Tools и API проходят. Вход, сборка пазла, расчёт, список заказчиков и управление пользователями проверены в настоящих окнах Windows.
- По 15 интеграционных проверок каждой СУБД: количество исходных заказчиков, полный расчёт, создание пользователя, пароль и его изменение, пазл, сохраняемая блокировка, разблокировка, сброс счётчика, дубликат логина, ограничение административных действий и формат заметок. Проверочные записи удаляются самим тестом.
- Оба маршрута дают 14 374,28. Данные восстановлены из выгрузок в отдельные `dkip2027_restore`: 5 заметок и тот же результат. Машинный отчёт: `restore-results.json`.
- На компьютере проверки PostgreSQL использует отдельный кластер на порту **55437**, чтобы не менять существующий сервер. В переносимой инструкции указан обычный порт 5432: читатель задаёт свой порт и пароль.

## API и модуль 6

- 18 живых HTTP-сценариев двух маршрутов: обычный список, второй путь, фильтр, [], неверное число, повторный/неизвестный параметр и настоящий отказ подключения к БД. Отчёт: `api-results.json`.
- Коллекции Postman выполнены Newman: по 5 запросов и 11 утверждений для каждой СУБД. Отчёты: `postman-results-mysql.json`, `postman-results-postgresql.json`.
- Swagger UI открыт локально, запросы действительно отправлены серверу. Отдельные процессы на 5281/5282 с неверным портом БД воспроизводят 500 без остановки рабочей базы.
- Postman Lightweight использован для снимков живых ответов и тестов без входа в чужую учётную запись. Для интерфейса коллекций нужно полноценное рабочее пространство Postman; Newman выполняет приложенную коллекцию без входа.
- Исходный DOCX заполнен с сохранением остальных частей документа. Обе версии открыты в Word, экспортированы в PDF и просмотрены. Структура исходных таблиц сохранена; коды HTTP размещены целиком на второй странице.
- Swagger проверяет `minimum: 1` до отправки. Настоящий ответ 400 проверяется запросом `user_id=abc` через Postman, браузер или коллекцию.

## Учебный сайт

Статические проверки контролируют 6 заданий, время и баллы, совпадение количества шагов, наличие исходников и изображений, поля/FK модели, 30 вариантов и OpenAPI. Браузерная проверка охватывает оба маршрута, все разделы, ER, сохранение паузы, документы и презентацию, размеры desktop/mobile. Подробный результат браузерного прогона — `browser-results.json`.

Изображения представляют настоящие окна приложений, страницы браузера и исходный PDF. Один снимок может сопровождать несколько шагов, когда на них разбирается один экран; подпись описывает именно изображённое. Снимок окна создания базы показывает заполнение формы, а наличие созданных таблиц подтверждено отдельным снимком и запросами.

## Повторить

```powershell
npm run build
npm test
# В окне с DKIP_STACK и DKIP_CONNECTION нужной учебной БД:
dotnet run --project examples/Tools -- test 'materials/basic/Задание 1/Заказчики.json'
# После запуска двух рабочих API и двух отдельных процессов проверки 500:
node tests/api-live.mjs
npx newman run docs/postman-mysql.json
npx newman run docs/postman-postgresql.json
```

Проверки выполнены в локальной учебной среде. GitHub Pages размещает статический курс; база, оконные приложения и API запускаются на компьютере преподавателя по инструкции.


## Гиды, таймер и предметные области · 28.09.2026

Гиды выделяют текущий элемент рамкой, прокручивают его в видимую область и располагают пояснение рядом. Проверены общий тур, разбор урока, тренировка, пробный экзамен, ER по шагам, готовая ER и файлы. Таймер расположен с отступом 24 px от условия на широком экране и после условия на мобильном.

`npm run build` и `npm test`: 11 проверок пройдены. `scripts/check-ui-fixes.js.txt`: 292 браузерные проверки на ширинах 1360 и 390 px, оба стека, все 180 условий заданий, сохранение паузы тренировки и непрерывного таймера экзамена. Отдельно проверены 6 шагов гидов готовой ER и файлов. Ошибок JavaScript не обнаружено.

`content/domains.txt` содержит 30 авторских производственных областей. `scripts/prepare-variants.py` создаёт условия, 120 Excel-документов, заказчиков и 5 заметок для каждого варианта. `scripts/check-variants.py` сверяет документы и 30 опубликованных при сборке ZIP: идентификаторы, цены, нормы, плановый расход и содержимое файлов. Excel-документы отрисованы; в Microsoft Excel дополнительно проверены даты, ведущие нули и норма 0,001. Новые условия используют отдельное пространство прогресса `domains-v2`; прежние локальные записи не удаляются.
