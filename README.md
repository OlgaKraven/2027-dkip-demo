# ДЭ 2027 · Специалист по информационным системам

Учебный разбор **КИМ 09.02.07-5-2027, ГИА, базовый уровень**: 6 заданий, 210 минут, 75 баллов.

[Открыть курс](https://olgakraven.github.io/2027-dkip-demo/) · [Запуск приложений](examples/README.md) · [Аудит и проверка](docs/audit/2026-11-04-baseline.md) · [Допущения](docs/DECISIONS.md)

Два полных маршрута: Windows Forms + XAMPP/MySQL и WPF + PostgreSQL. В каждом 123 шага с действиями и наблюдаемым результатом. Проекты создаются и запускаются через Visual Studio; SQL выполняется в интерфейсе СУБД. Код дан для сверки, реальные снимки показывают обозначенное в подписи состояние. Модуль 6 содержит 20 шагов для преподавателя без опыта API: адрес, GET, JSON, Swagger UI, OpenAPI, HTTP-ответы и заполнение исходного шаблона DOCX.

Сайт сохраняет структуру и оформление заданного шаблона. Обучение, тренировка с отдельным экраном паузы, завершением и новой попыткой, непрерывный пробный экзамен с 30 авторскими вариантами, примеры, критерии и презентация преподавателя. Пользовательский прогресс хранится в браузере; автоматической оценки решений нет.

## Запустить сайт

Нужен Node.js 22 или новее.

```powershell
npm ci
npm run build
npm test
npm run preview
```

Открыть http://127.0.0.1:4198. Сборка для публикации находится в `site`. GitHub Actions собирает и публикует её через GitHub Pages.

## Запустить программы

Следуйте [инструкции для Visual Studio](examples/README.md): создайте новую базу, выполните SQL, настройте профиль запуска, загрузите данные, запустите интерфейс и отдельный API. Нужны Windows, Visual Studio с компонентами .NET 10 для классических и веб-приложений и соответствующий сервер БД. XAMPP поставляет MariaDB с совместимым для этого примера SQL.

Демонстрационные записи: `admin / Demo2027!`, `student / Demo2027!`. Это учебные данные разработчика. Учебный сайт не запускает EXE и не подключается к локальной БД автоматически.

| Маршрут | Приложение | Swagger после запуска | OpenAPI |
|---|---|---|---|
| MySQL | `examples/mysql/Dkip.WinForms.csproj` | http://127.0.0.1:5271/swagger/ | http://127.0.0.1:5271/openapi.json |
| PostgreSQL | `examples/postgresql/Dkip.Wpf.csproj` | http://127.0.0.1:5272/swagger/ | http://127.0.0.1:5272/openapi.json |

Исходники обеих программ доступны на сайте в ZIP. Схема содержит 12 таблиц и 14 связей; [векторный PDF](materials/er.pdf) соответствует SQL и интерактивному разбору. Документация: [MySQL DOCX](docs/api-mysql.docx), [PostgreSQL DOCX](docs/api-postgresql.docx), [OpenAPI](docs/openapi.json).

## Источники и устройство

- Условие и исходные приложения предоставлены пользователем из комплекта 2027 года: `materials/kim-2027.pdf`, `materials/basic`. Значения в оригиналах не исправлялись. Манифест SHA-256 формируется при сборке.
- Дизайн и общие компоненты: [demo-rvpm-2027](https://github.com/OlgaKraven/demo-rvpm-2027), commit `a5510ee36faaa291ff42a95066a4070c5e7be88f`.
- `src` — интерфейс; `content` — объяснения, модель, варианты и подписи; `examples` — C# и SQL; `docs` — контракт и документация; `materials/screenshots` — реальные снимки; `scripts` — сборка и воспроизводимые подготовительные операции.

Авторские варианты помечены как учебные и не выдаются за официальные. Спорные единицы, коды и тарифы разобраны в `docs/DECISIONS.md`. Расчёт примера — **14 374,28** при явно указанных допущениях.

Swagger UI распространяется вместе с локальным API; его лицензия сохранена в `examples/Api/wwwroot/LICENSE`. Носорог и оформление взяты из предоставленного пользователем шаблона.
