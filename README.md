# ДЭ 2027 · Специалист по информационным системам

Учебный разбор **КИМ 09.02.07-5-2027, ГИА, базовый уровень**: 6 заданий, 210 минут, 75 баллов.

[Открыть курс](https://olgakraven.github.io/2027-dkip-demo/) · [Запуск приложений](examples/README.md) · [Проверки](docs/QA.md) · [Допущения](docs/DECISIONS.md)

Два полных маршрута: Windows Forms + XAMPP/MySQL и WPF + PostgreSQL. В каждом 72 микрошагa с действиями, объяснениями, самопроверкой, кодом и изображениями настоящих программ или исходных документов. Модуль 6 содержит 20 шагов для преподавателя без опыта API: адрес, GET, JSON, Swagger UI, OpenAPI, HTTP-ответы и заполнение исходного шаблона DOCX.

Сайт сохраняет структуру и оформление заданного шаблона. Обучение, тренировка с паузой, 30 авторских пробных вариантов, примеры, критерии и презентация преподавателя. Пользовательский прогресс хранится в браузере; автоматической оценки решений нет.

## Запустить сайт

Нужен Node.js 22 или новее.

```powershell
npm ci
npm run build
npm test
npm run preview
```

Открыть http://127.0.0.1:4198. Сборка для публикации находится в `site`. GitHub Actions собирает и публикует её через GitHub Pages.

## Запустить программы

Следуйте [инструкции Windows](examples/README.md): создайте новую базу, выполните SQL, задайте переменные подключения, загрузите данные, запустите интерфейс и отдельный API. Нужны Windows, .NET SDK 10 и соответствующий сервер БД. XAMPP поставляет MariaDB с совместимым для этого примера SQL.

Демонстрационные записи: `admin / Demo2027!`, `student / Demo2027!`. Это учебные данные разработчика. Учебный сайт не запускает EXE и не подключается к локальной БД автоматически.

| Маршрут | Приложение | Swagger после запуска | OpenAPI |
|---|---|---|---|
| MySQL | `examples/mysql/Dkip.WinForms.csproj` | http://127.0.0.1:5271/swagger/ | http://127.0.0.1:5271/openapi.json |
| PostgreSQL | `examples/postgresql/Dkip.Wpf.csproj` | http://127.0.0.1:5272/swagger/ | http://127.0.0.1:5272/openapi.json |

Исходники обеих программ доступны на сайте в ZIP. Схема содержит 12 таблиц и 14 связей; [векторный PDF](materials/er.pdf) соответствует SQL и интерактивному разбору. Документация: [MySQL DOCX](docs/api-mysql.docx), [PostgreSQL DOCX](docs/api-postgresql.docx), [OpenAPI](docs/openapi.json).
