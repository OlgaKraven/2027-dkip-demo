# ДЭ 2027 · Специалист по информационным системам

Подготовка к ГИА базового уровня по КИМ 09.02.07-5-2027. В экзамене шесть заданий на 210 минут, максимальная оценка — 75 баллов.

В курсе два учебных маршрута — Windows Forms с XAMPP и MySQL или WPF с PostgreSQL. В задания входят разработка ASP.NET Core Minimal API, проверка запросов в Postman и оформление документации.
