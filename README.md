# ДЭ 2027 · Специалист по информационным системам

Учебный разбор **КИМ 09.02.07-5-2027, ГИА, базовый уровень**: 6 заданий, 210 минут, 75 баллов.

[Открыть курс](https://olgakraven.github.io/2027-dkip-demo/) · [Запуск приложений](examples/README.md) · [Аудит и проверка](docs/audit/2026-11-04-baseline.md) · [Допущения](docs/DECISIONS.md)

Два полных маршрута: Windows Forms + XAMPP/MySQL и WPF + PostgreSQL. В каждом — шаги с действиями и наблюдаемым результатом. Проекты создаются и запускаются через Visual Studio; SQL выполняется в интерфейсе СУБД. Код дан для сверки, реальные снимки показывают обозначенное в подписи состояние. В заданиях 5 и 6 студенты создают ASP.NET Core Minimal API, проверяют его через Postman и заполняют исходный шаблон DOCX.

Сайт сохраняет структуру и оформление заданного шаблона. Обучение, тренировка с отдельным экраном паузы, завершением и новой попыткой, непрерывный пробный экзамен с 30 авторскими вариантами, примеры, критерии и презентация преподавателя. Пользовательский прогресс хранится в браузере; автоматической оценки решений нет.

## Запустить сайт

Нужен Node.js 22 или новее.

```powershell
npm ci
npm run build
npm test
npm run preview
```

Открыть http://127.0.0.1:4198. Сборка для публикации находится в `site`. GitHub Actions собирает и публикует её через GitHub Pages.

## Запустить программы

Следуйте [инструкции для Visual Studio](examples/README.md): создайте новую базу, выполните SQL, настройте профиль запуска, загрузите данные, запустите интерфейс и отдельный API. Нужны Windows, Visual Studio с компонентами .NET 10 для классических и веб-приложений и соответствующий сервер БД. XAMPP поставляет MariaDB с совместимым для этого примера SQL.

Демонстрационные записи: `admin / Demo2027!`, `student / Demo2027!`. Это учебные данные разработчика. Учебный сайт не запускает EXE и не подключается к локальной БД автоматически.

| Маршрут | Приложение | Запрос после запуска | OpenAPI |
|---|---|---|---|
| MySQL | `examples/mysql/Dkip.WinForms.csproj` | http://127.0.0.1:5271/notes | http://127.0.0.1:5271/openapi.json |
| PostgreSQL | `examples/postgresql/Dkip.Wpf.csproj` | http://127.0.0.1:5272/notes | http://127.0.0.1:5272/openapi.json |

Исходники обеих программ доступны на сайте в ZIP. Схема содержит 12 таблиц и 14 связей; [векторный PDF](materials/er.pdf) соответствует SQL и интерактивному разбору. Документация: [MySQL DOCX](docs/api-mysql.docx), [PostgreSQL DOCX](docs/api-postgresql.docx), [OpenAPI](docs/openapi.json).

## Презентация для занятия

- [Windows Forms + MySQL / MariaDB](https://olgakraven.github.io/2027-dkip-demo/deck.html?stack=mysql) · [PDF](materials/presentation-dkip2027-winforms.pdf)
- [WPF + PostgreSQL](https://olgakraven.github.io/2027-dkip-demo/deck.html?stack=postgresql) · [PDF](materials/presentation-dkip2027-wpf.pdf)

Условия КИМ, все шаги выбранного маршрута и показ готового примера. В разделе «Преподавателю» впишите ФИО, должность и кафедру. «Режим показа» открывает отдельное окно для аудитории. Для PDF с вашими данными выберите «Ещё» → «Печать / сохранить PDF».

Для обновления скачиваемых PDF после изменения слайдов: один раз выполните `npx playwright install chromium`, затем `npm run export:pdf`. Сохраните в Git оба PDF и `content/presentation-pdfs.json`. Проверка перед публикацией сверяет содержимое и оформление слайдов с версией, для которой выгружен каждый PDF.
