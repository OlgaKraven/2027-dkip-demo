0. Установка и настройка программ

Visual Studio 2026 и .NET SDK

  1. На странице Visual Studio выберите Community → «Бесплатная загрузка» и запустите скачанный установщик. В Visual Studio Installer отметьте «Разработка классических приложений .NET» и «ASP.NET и разработка веб-приложений».
  2. На странице .NET 10 найдите SDK → Windows → x64 и установите SDK, если он ещё отсутствует. В новом окне PowerShell выполните dotnet --list-sdks. Для основного маршрута в списке должна быть версия 10.0.x.
  3. Откройте Visual Studio 2026 и проверьте наличие шаблонов Windows Forms App, WPF Application и ASP.NET Core Empty для C#.

Windows Forms и XAMPP

На странице XAMPP выберите установщик XAMPP для Windows x64. Оставьте MySQL, Apache и phpMyAdmin. В XAMPP Control Panel запустите Apache и MySQL. Откройте phpMyAdmin. Если в учебной конфигурации Apache слушает другой порт, допишите его после localhost.

WPF и PostgreSQL

На странице PostgreSQL для Windows нажмите Download the installer. Выберите Windows x86-64. В установщике отметьте PostgreSQL Server, pgAdmin 4 и Command Line Tools. Запишите пароль postgres и выбранный порт, обычно 5432. В pgAdmin откройте зарегистрированный локальный сервер и раскройте Databases.

Если при импорте, выгрузке или восстановлении pgAdmin показывает Utility file not found, откройте Preferences → Paths → Binary paths. В блоке PostgreSQL Binary Path в строке своей версии укажите папку bin установленного PostgreSQL, например C:\Program Files\PostgreSQL\18\bin. Нажмите Validate и проверьте, что в окне появились версии pg_dump, pg_restore и psql. Нажмите OK, затем Save и повторите действие.

Диаграмма, документы и проверка API

На странице diagrams.net Desktop откройте Assets. Скачайте установщик draw.io-…-windows-installer.exe или переносимый архив draw.io-…-windows.zip. Извлеките весь ZIP в отдельную папку и откройте draw.io.exe. Создайте пустую диаграмму и проверьте меню File → Export as → PDF.

На странице Postman нажмите Windows x64 и установите приложение. До отключения интернета откройте рабочую область, разрешённую для тренировки, и проверьте кнопку Import. На экзамене используйте подготовленный площадкой стенд и выданную учётную запись, если вход обязателен.

Для прогона коллекции без рабочей области заранее скачайте Postman CLI для Windows x64 (ZIP). Распакуйте ZIP в папку postman-cli. Сохраните вместе postman-cli.exe и папку lib. Команды запуска своего локального файла приведены в задании 5.

Проверьте, что открываются DOCX, XLSX, PDF и RAR. Если нужно, скачайте LibreOffice и 7-Zip для Windows x64.

Библиотеки и разработка без интернета

Подключите пакеты в новом проекте

Заранее скачайте набор NuGet-пакетов для MySQL или для PostgreSQL. Распакуйте папку nuget-packages и файл NuGet.Config рядом с файлом решения. Оставьте .nupkg целыми. В набор входят драйвер и его зависимости. Отдельные пакеты драйверов доступны на NuGet: MySqlConnector 2.6.1 и Npgsql 10.0.1.

В Visual Studio выберите проект с кодом БД → «Управление пакетами NuGet» → «Обзор» → источник «Пакеты из архива». Установите драйвер выбранной СУБД и соберите решение без сети. При NU1101 или NU1102 сверьте имя и версию отсутствующего пакета с содержимым папки.

В PowerShell из папки своего решения выполните команды ниже. Первая использует только локальный NuGet-источник, вторая собирает проект с уже восстановленными пакетами.

dotnet restore --configfile NuGet.Config --no-http-cache
dotnet build --no-restore

В обозревателе решений Visual Studio назначьте стартовым свой оконный проект или Api. Для API заполните переменные подключения в профиле отладки, как показано в карточке. Запустите F5 и проверьте созданную базу.

Если на стенде .NET 9

.NET 10 — долгосрочный выпуск (LTS). Поддержка .NET 9 завершилась 10 ноября 2026 года. Для стенда с .NET 9 заранее скачайте и установите .NET 9 SDK для Windows x64. Оба выпуска можно использовать в Visual Studio 2026.

В папке отдельной копии учебного решения создайте файл global.json. Впишите установленную версию 9.0.x из dotnet --list-sdks. latestPatch разрешает выбрать более новый патч той же полосы SDK. Команда dotnet --version из этой папки должна показать 9.0.x.

{
  "sdk": {
    "version": "9.0.321",
    "rollForward": "latestPatch"
  }
}

В новом проекте выберите .NET 9 в мастере Visual Studio. Если проект уже создан, замените net10.0-windows на net9.0-windows в настольном .csproj, а net10.0 на net9.0 в библиотеке, API и импортёре. Для Npgsql под .NET 9 понадобятся Microsoft.Extensions.Logging.Abstractions и Microsoft.Extensions.DependencyInjection.Abstractions версии 9.0.0 из локального набора. Откройте решение в Visual Studio 2026 после сохранения global.json. Восстановите локальные пакеты, соберите проект и запустите F5.
