0. Установка и настройка программ

  1. Скачайте установщик Visual Studio Community. Выберите «Разработка классических приложений .NET» и «ASP.NET и разработка веб-приложений». Для Windows Forms, WPF и API из ZIP нужны Visual Studio 2026 и .NET 10 SDK для Windows x64. Проверьте dotnet --list-sdks в PowerShell.
  2. Для маршрута Windows Forms скачайте XAMPP. Оставьте MySQL, Apache и phpMyAdmin. В XAMPP Control Panel запустите MySQL и Apache. Проверьте вход в http://localhost/phpmyadmin.
  3. Для WPF скачайте PostgreSQL с pgAdmin для Windows. Выберите сервер, pgAdmin 4 и Command Line Tools. Запишите пароль postgres и порт, обычно 5432. Откройте в pgAdmin ветку Databases.
  4. Установите diagrams.net Desktop (Windows installer), проверьте экспорт ER в PDF. Для API скачайте Postman для Windows x64 и проверьте импорт локальной коллекции. Если Postman требует вход в аккаунт, для домашней офлайн-проверки используйте Invoke-RestMethod.
  5. Проверьте, что открываются DOCX, XLSX, PDF и RAR. Если не хватает программ, скачайте LibreOffice или 7-Zip для Windows x64.

Проверьте запуск готового примера

Восстановите заполненную базу

Распакуйте ZIP выбранного стека. В phpMyAdmin или pgAdmin создайте пустую базу dkip2027_course с UTF-8. В этой базе выполните examples/mysql/Sql/01-schema.sql и 02-demo-data.sql из той же папки. Для PostgreSQL возьмите оба файла из examples/postgresql/Sql. В таблицах будут шесть исходных заказчиков и служебные контрагенты для расчёта, два пользователя и пять заметок.

Запустите готовые приложения

Для запуска Windows Forms/WPF установите .NET Desktop Runtime 10, для API — ASP.NET Core Runtime 10, если они не установлены вместе с SDK. Откройте PowerShell в корне ZIP и выберите одну строку подключения. Пример для MySQL:

$env:DKIP_STACK='mysql'
$env:DKIP_CONNECTION='Server=127.0.0.1;Port=3306;Database=dkip2027_course;User ID=root;Password=;Character Set=utf8mb4'
Start-Process .\Windows\Desktop\Dkip.WinForms.exe

Пример для PostgreSQL. Замените ВАШ_ПАРОЛЬ и при необходимости порт или имя пользователя:

$env:DKIP_STACK='postgresql'
$env:DKIP_CONNECTION='Host=127.0.0.1;Port=5432;Database=dkip2027_course;Username=postgres;Password=ВАШ_ПАРОЛЬ'
Start-Process .\Windows\Desktop\Dkip.Wpf.exe

Для входа используйте admin и student с учебным паролем Demo2027!. Соберите пазл, затем нажмите «Войти». DLL и папку Assets держите рядом с EXE. Для API перейдите в Windows\Api в том же окне PowerShell и запустите:

Set-Location .\Windows\Api
.\Dkip.Api.exe --urls http://127.0.0.1:5271

В другом окне PowerShell выполните Invoke-RestMethod http://127.0.0.1:5271/notes. Ожидаются пять заметок. Для маршрута PostgreSQL используйте порт 5272 в обеих командах, если проверяете коллекцию docs/postman-postgresql.json.

Библиотеки и разработка без интернета

Соберите проект из исходников

В корне ZIP откройте PowerShell и выполните:

dotnet restore Dkip.Example.slnx --configfile NuGet.Config --no-http-cache
dotnet build Dkip.Example.slnx --no-restore

Откройте Dkip.Example.slnx в Visual Studio. Назначьте Dkip.WinForms, Dkip.Wpf либо Dkip.Api стартовым проектом и укажите те же переменные DKIP_STACK и DKIP_CONNECTION в свойствах отладки. Запустите через F5.

Подключите пакеты в новом проекте

Пока есть интернет, скачайте ZIP и скопируйте папку nuget-packages и NuGet.Config к своему решению. Отдельные драйверы можно скачать по ссылкам MySqlConnector 2.6.1 и Npgsql 10.0.1. Оставьте файлы .nupkg целыми и возьмите из ZIP их зависимости.

В Visual Studio выберите проект с кодом БД → «Управление пакетами NuGet» → «Обзор» → источник «Пакеты из архива». Установите драйвер выбранной СУБД и соберите решение без сети. При NU1101 или NU1102 сверьте имя и версию отсутствующего пакета с содержимым папки.

Если на стенде .NET 9

.NET 10 — выпуск с долгосрочной поддержкой (LTS). Поддержка .NET 9 завершилась 10 ноября 2026 года. Если на стенде требуется .NET 9, заранее установите .NET 9 SDK для Windows x64 и используйте Visual Studio 2026. Для решения .slnx нужен SDK 9.0.2xx или 9.0.3xx. Выберите установленный SDK через global.json по шагу 5 в README.md и проверьте dotnet --version из корня распакованной копии.

В отдельной копии в .csproj настольного проекта замените net10.0-windows на net9.0-windows. В проектах Shared, Api, Tools и учебном starter/<стек>/Import замените net10.0 на net9.0. Версии драйверов сохраняются. Для Npgsql под .NET 9 нужны Microsoft.Extensions.Logging.Abstractions и Microsoft.Extensions.DependencyInjection.Abstractions версии 9.0.0. Оба пакета уже входят в ZIP. Повторите dotnet restore и dotnet build, затем выполните F5 с прежними настройками СУБД. Готовые EXE из ZIP остаются сборками .NET 10.
